Commits signed with GPG lead to JSONDecodeError
I discovered this bug in [this commit](https://gitlab.com/carmenbianca/schaakmat/tree/7a99f12819e9b4734a8fa48e726cd501cc96f8e8) on my project.

To reproduce in any other project:

- `git commit --alow-empty --gpg-sign=$YOUR_KEYID -m "empty signed commit"`
- `python setup.py sdist`
- `cd dist`
- `pip install $YOUR_TAR_FILE`
- Then open Python and import your project, you will see:
  ```
  >>> import schaakmat
  Traceback (most recent call last):

    File "/home/carmen/Projects/schaakmat/dist/schaakmat-0.1.0+206.g7a99f12/src/schaakmat/_version.py", line 21, in get_versions
      return json.loads(version_json)
    File "/usr/lib/python3.5/json/__init__.py", line 319, in loads
      return _default_decoder.decode(s)
  ```
